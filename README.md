# Apex Fitness Landing Page

A professional, high performance landing page designed for a modern fitness center. This project demonstrates semantic HTML5 structure, mobile-first responsive design, and a professional Git workflow.

## Business Rationale
**Company Goal:** To increase gym memberships by showcasing a high energy environment, professional coaching, and a seamless user experience.

**Target Audience:**
- Busy professionals looking for efficient workout plans.
- Fitness enthusiasts seeking a community driven environment.
- Beginners looking for guided personal training.

**Design Strategy:** The layout uses a high contrast color palette to evoke energy and "Call to Action" (CTA) buttons strategically placed to convert visitors into leads via the contact form.

## Features
- **Hero Section:** Bold value proposition with a clear CTA.
- **Services:** Highlighting Personal Training, Group Classes, and Nutrition.
- **About/Team:** Building trust through professional expertise.
- **Interactive Form:** Contact form with built in browser validation.
- **Accessibility:** ARIA landmarks, alt text for images, and logical heading hierarchy ($H1$ through $H3$).
- **SEO Optimized:** Meta descriptions and semantic tags for better search engine indexing.

## Technologies Used
- **HTML5:** Semantic structure.
- **Git/GitHub:** Version control with feature based branching.
- **GitHub Pages:** Deployment and hosting.
